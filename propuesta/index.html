Propuesta — Landing Page

Claro, directo, sin sorpresas.

Esta propuesta cubre el servicio de Landing Page ($360 lanzamiento / $600 regular). Web + Sistema Interno se cotiza por separado.

Qué incluye

  • Diseño personalizado desde cero — sin templates, sin WordPress, sin constructores de páginas
  • Código HTML / CSS / JS puro y limpio, escrito a mano
  • Registro de dominio .cl (NIC Chile)
  • Hosting en servidor real — incluido el primer año
  • HTTPS / SSL — certificado TLS con renovación automática
  • DNS configurado y apuntado correctamente desde el primer día
  • Diseño responsive — móvil, tablet y escritorio
  • Velocidad optimizada — sin plugins, sin librerías innecesarias
  • Meta tags completos (título, descripción, og:image para previsualizaciones en WhatsApp y redes)
  • Configuración de Google Search Console para indexación inmediata
  • Botón de contacto WhatsApp integrado
  • Hasta 2 rondas de revisión incluidas
  • Entrega en máximo 2 semanas — garantía de devolución si no se cumple

Qué no incluye

  • Redacción de textos (el cliente provee el contenido, o se cotiza aparte)
  • Fotografía profesional
  • Ilustración o diseño gráfico personalizado
  • Pasarela de pagos (Transbank, MercadoPago, etc.)
  • Login de usuarios o áreas privadas
  • Base de datos propia o lógica de servidor
  • Mantenimiento mensual (puede cotizarse por separado)

Plazos y garantía

Entrega máxima: 2 semanas desde el pago inicial. Si no se cumple por cualquier motivo, devolución completa sin preguntas. Se incluyen hasta 2 rondas de revisión.

Pago

50% al inicio, 50% en entrega. Proyectos sobre USD $1.000: pago en 6 cuotas mensuales disponible a solicitud. Transferencia bancaria o método acordado. Sin sorpresas.

Comunicación

WhatsApp como canal principal. Respuesta el mismo día, todos los días.

Entrega y acceso

El sitio queda operativo en el dominio .cl. El hosting es administrado por FCB. El cliente recibe acceso completo al dominio y credenciales NIC Chile.
